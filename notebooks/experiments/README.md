## 書き方

**1つの Notebook で1つの工夫に絞る。**
複数を同時に変えると、点数が動いたときどれが効いたか分からない。

**採点条件を `tutorial/04_model.ipynb` と揃える。**
`train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)` を使う。

**分け方を何通りか変えて平均で比べる。**
採点相手が変わるだけで AUC は 0.7636〜0.9198 まで動く。
1通りの結果では、数ポイントの差が工夫の成果か偶然かを判定できない。

**投稿は1日5回まで。** 手元で良くなったものだけ投稿する。

各 Notebook に次を書き残す。

- 何を試すか
- なぜ効きそうか
- 手元での点数（工夫の前後を並べる）
- 効いたかどうかと、その理由の見当

**効かなかった検証も残す。** 上の表にも結果を記録する。

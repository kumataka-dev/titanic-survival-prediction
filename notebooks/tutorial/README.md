# tutorial

乗客の情報から生死を予測し、提出ファイルを作るまでの5つの Notebook。
**番号順に実行する。**

| Notebook | やること | 読み込み | 書き出し |
| --- | --- | --- | --- |
| [01_overview.ipynb](01_overview.ipynb) | 項目と、値が入っていない場所を確認する | `data/raw/` | — |
| [02_analysis.ipynb](02_analysis.ipynb) | どんな人が生き残ったかを調べる | `data/raw/` | — |
| [03_preprocess.ipynb](03_preprocess.ipynb) | 空いている場所を埋め、文字を数字に置き換える | `data/raw/` | `data/processed/` |
| [04_model.ipynb](04_model.ipynb) | 予測する仕組みを作り、生存確率を出す | `data/processed/` | `data/processed/` |
| [05_submit.ipynb](05_submit.ipynb) | 予測を投稿できる形に整える | `data/processed/` | `data/submissions/` |

05 まで実行すると `data/submissions/submit.csv` ができる。これを投稿する。

## 使っている手法

| | 内容 |
| --- | --- |
| 欠損の埋め方 | `age` は平均値（29.70）、`embarked` は最頻値（`S`） |
| 文字の変換 | `get_dummies()` で 0/1 の項目に分解。項目数 8 → 11 |
| 予測の仕組み | 標準化 + ロジスティック回帰 |
| 成績の測り方 | 445 人を 356 人 / 89 人に分け、89 人で採点 |

## 成績

| | 値 |
| --- | --- |
| 手元の正解率 | 0.7528（全員「助からない」と答えた場合は 0.5955） |
| 手元の AUC | 0.7636〜0.9198（分け方により変動。平均 0.8475） |
| Public スコア | 0.8514 |

分かったこと。

生存率で見ると、**性別の差が最も大きい**。

- 性別 — 女性 77.6% / 男性 20.1%（差 57.5 ポイント）
- 客室の等級 — 1等 68.5% / 2等 44.3% / 3等 25.8%（差 42.7 ポイント）
- 掛け合わせると 3等の女性（58.5%）が1等の男性（43.6%）を上回る

一方でモデルの重みでは、**客室の等級が最も大きい**（`pclass` -0.797 / `sex` ±0.637）。
生存率は項目を1つずつ単独で見るのに対し、重みは他の項目の影響を除いた上で測るため、
順序が入れ替わる。

## 各章の要点

| 章 | 要点 |
| --- | --- |
| 01 | `age` と `embarked` に空きがある。`sex` と `embarked` は文字なので数字に置き換える |
| 02 | 相関係数は一方向の増減しか捉えない。`age` が -0.081 と弱く見えるのはこのため。モデルの重みでは -0.445 と大きい |
| 03 | `.mode()` はリストを返すので `[0]` が必要。付け忘れるとエラーも出ずに埋まらない |
| 04 | 項目ごとに数字の大きさが違うので標準化が必要。入れないと計算が終わらない |
| 05 | 採点方法が AUC なので確率のまま出す。`0/1` に丸めると 0.81 → 0.73 に落ちる |

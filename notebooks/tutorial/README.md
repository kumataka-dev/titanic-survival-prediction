# tutorial — 一通りの流れ

タイタニック号の乗客名簿から、誰が生き残ったかを言い当てて提出するまでの流れを、
段階ごとに分けたもの。**番号順に実行する。**

ここは**型を覚えるための部分**で、自分の工夫はまだ入っていない。
改善は [experiments/](../experiments/) 側で行う。

## ここまでの到達点

| | 値 |

分かったことは、**性別と客室の等級が決定的**だということ。
女性 77.6% に対して男性 20.1%、1等 68.5% → 3等 25.8%。

## 各章で押さえておきたい点

| 章 | 要点 |
| --- | --- |
| 01 | `age` と `embarked` に空きがある。`sex` と `embarked` は文字なので数字に置き換える必要がある |
| 02 | 相関係数は「一方向に増えるほど増える」関係しか捉えられない。`age` が弱く見えたのはこのため |
| 03 | `.mode()` はリストを返すので `[0]` が必要。付け忘れると**エラーも出ずに埋まらない** |
| 04 | 項目ごとに数字の大きさが違いすぎるので標準化が必要。入れないと計算が終わらない |
| 05 | 採点方法が AUC なので**確率のまま出す**。`0/1` に丸めると 0.81 → 0.73 に落ちる |
